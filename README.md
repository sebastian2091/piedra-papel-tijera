# Piedra, Papel o Tijera 🎮

Juego de **Piedra, Papel o Tijera** desarrollado en Python como proyecto de práctica.

## 📌 Descripción

El programa permite al usuario elegir entre:

* 🪨 Piedra
* 📄 Papel
* ✂️ Tijera

La computadora realiza una elección aleatoria y el programa determina si el jugador **gana, pierde o empata**.

## 🛠️ Tecnologías utilizadas

* Python 3
* Módulo `random`
* Listas
* Condicionales `if`, `elif` y `else`
* Operadores lógicos
* `input()` y conversión de datos con `int()`

## ▶️ Cómo ejecutar el proyecto

1. Tener Python instalado.
2. Descargar o clonar este repositorio.
3. Ejecutar el archivo:

```bash
python piedra_papel_tijera.py
```

4. Elegir una opción:

   * `1` → Piedra
   * `2` → Papel
   * `3` → Tijera
